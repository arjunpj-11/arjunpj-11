### <img src="./assets/imminiq-logo.svg" width="32" height="32" align="absmiddle" alt="Imminiq Logo"/> **Imminiq** — *Learning Infrastructure & AI Collaboration Platform*

<blockquote style="border-left: 4px solid #f15a35;">
  <p><b><font color="#f15a35">"AI starts the learning path. The community continuously improves it."</font></b></p>
</blockquote>

- **Overview & Assessment**: Imminiq is a full-stack, AI-assisted learning platform designed to replace static, fragmented learning resources with community-evolving roadmaps. AI generates initial structured learning tracks (topics, subtopics, lessons), while community discussions, verification votes, and peer contributions keep content accurate and up-to-date.
- **Architecture & Highlights**:
  - 🔄 **Background Processing**: Redis + BullMQ for asynchronous jobs and AI roadmap generation
  - ⚡ **Real-Time System**: Socket.IO & WebRTC for presence, messaging, and peer video/audio calls
  - 💻 **Code Execution & Contextual AI**: Integrated Piston execution engine & LLM context support
  - 🎯 **Quality Standards**: Clean Architecture design backed by 470+ passing automated tests
- **Tech Stack**: `React` · `TypeScript` · `Express.js` · `MongoDB` · `Redis` · `BullMQ` · `Socket.IO` · `WebRTC`

### <img src="./assets/arni-logo.png" width="32" height="32" align="absmiddle" alt="ArNI Logo"/> **ArNI** — *Full-Stack E-Commerce System*

<blockquote style="border-left: 4px solid #2563EB;">
  <p><b><font color="#2563EB">"Complete transaction-based product covering customer journeys, payments, fulfillment, and administration."</font></b></p>
</blockquote>

- **Overview & Assessment**: ArNI is a complete, full-stack e-commerce system built to handle end-to-end commerce logic. It integrates storefront shopping flows with an operational backend for stock, orders, returns, and sales analytics.
- **Key Features**:
  - 🛒 **Customer Workflow**: Session auth, catalog filtering, variant selection, shopping cart, multi-address checkout, wallet system, order tracking, and product return requests
  - 💳 **Payment & Security**: Integrated Razorpay payment gateway, wallet transactions, and Cash-on-Delivery logic
  - 📊 **Admin Dashboard**: Comprehensive management for stock, products, categories, coupons, banners, user accounts, and sales reporting
- **Tech Stack**: `Node.js` · `Express.js` · `MongoDB` · `EJS` · `Razorpay` · `Cloudinary`
