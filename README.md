## 🚀 Featured Projects

### <img src="./assets/imminiq-logo.svg" width="32" height="32" align="absmiddle" alt="Imminiq logo"/> Imminiq — AI-Powered Community Learning Platform

<blockquote>
  <p><b>“Learn deeply. Build together.”</b></p>
</blockquote>

**Imminiq** is a completed and production-deployed learning platform where AI creates structured learning paths and learners continuously improve them through discussion, contribution, and community verification.

It combines structured roadmaps, adaptive assessments, mastery tracking, mock tests, contextual AI assistance, community collaboration, and real-time communication inside one learning environment.

#### Product Capabilities

- 🗺️ AI-generated learning roadmaps with topics, lessons, and structured progression
- 🧠 Adaptive learning, mastery tracking, mock tests, and progress analysis
- 🤝 Community contributions, verification, rewards, moderation, and tracker clans
- 💬 Real-time messaging, presence, notifications, and collaborative discussions
- 📞 WebRTC-powered audio and video calls
- 💻 Integrated code execution through Piston
- 🤖 Multi-provider AI workflows with provider fallback handling
- 🔐 Authentication, authorization, secure sessions, and protected administrative workflows

#### Engineering and Architecture

- 🧱 Backend organized using Strict Clean Architecture
- 📦 Feature modules separated into presentation, application, domain, and infrastructure layers
- 🔗 Explicit public module contracts prevent private cross-module imports
- 🧪 Automated architecture tests enforce frontend and backend module boundaries
- 🔄 Redis and BullMQ handle background processing and asynchronous AI generation
- ⚡ Socket.IO supports real-time messaging, presence, and event delivery
- ✅ 497 automated tests across frontend and backend suites

#### Production Infrastructure

- 🐳 Containerized application delivery using Docker
- ☁️ AWS infrastructure provisioned through CloudFormation
- 🖥️ Amazon EC2 for application workloads
- 📦 Amazon ECR for container-image storage
- 🗂️ Amazon S3 and CloudFront for asset storage and edge delivery
- 🔐 AWS Systems Manager and Doppler for secure runtime configuration
- 🚀 GitHub Actions workflows for automated CI/CD
- 🌐 Nginx and Caddy experience for reverse proxying, HTTPS, and hosting operations

**Built with:** `React` · `TypeScript` · `Node.js` · `Express.js` · `MongoDB` · `Redis` · `BullMQ` · `Socket.IO` · `WebRTC` · `Vitest` · `Supertest` · `Playwright` · `Docker` · `AWS`

### <img src="./assets/arni-logo.png" width="32" height="32" align="absmiddle" alt="Arni logo"/> Arni — My First End-to-End E-Commerce Project

<blockquote>
  <p><b>“The project that established my full-stack foundation.”</b></p>
</blockquote>

**Arni** was my first major full-stack project, created while studying MERN-stack development at Brototype. I built it to understand how the customer experience, backend logic, database, payments, inventory, and administrative operations connect inside a complete e-commerce application.

Arni represents the beginning of my practical software-engineering journey. It gave me hands-on experience translating business requirements into working application flows and building a complete system from the ground up.

#### Customer Experience

- 🛍️ Product browsing, searching, filtering, and variant selection
- 🛒 Shopping cart, wishlist, and multi-address checkout
- 🔐 Session-based authentication and account management
- 💳 Razorpay and cash-on-delivery payment workflows
- 💰 Wallet balances and transaction history
- 🏷️ Coupon and promotional-offer support
- 📦 Order tracking, cancellation, return, and refund requests

#### Administration and Operations

- 📦 Product, category, variant, and inventory management
- 🏷️ Coupon, offer, and banner management
- 👥 Customer-account administration
- 🚚 Order, return, refund, and fulfillment workflows
- 📊 Sales reports, analytics, and operational dashboards
- 🖼️ Cloudinary-backed product-image management

#### What the Project Taught Me

- Designing customer and administrative workflows together
- Structuring an Express.js application into maintainable modules
- Modeling products, variants, orders, wallets, coupons, and transactions in MongoDB
- Integrating an external payment gateway
- Handling authentication, validation, errors, and stateful business workflows
- Taking an application from an initial idea to a complete working system

**Built with:** `Node.js` · `Express.js` · `MongoDB` · `EJS` · `JavaScript` · `Razorpay` · `Cloudinary`
